2. Resistance versus temperature

Above Tc the normal state is modeled with ρ = ρ₀[1 + α(T − T₀)], a linear approximation that is only reliable near T₀ (OpenStax Sec. 9.3), so the low-temperature part of the curve is illustrative. Below Tc a superconductor has ρ = 0. The slider uses a square-root scale so low temperatures are easy to explore.

4. Meissner effect: magnetic levitation

Below Tc the superconductor excludes the magnet's field, so the magnet floats. Warm it above Tc (use the slider) and it loses levitation. Only works when a superconducting material is selected.

Field lines bend around the superconductor because B inside it is zero. This is a qualitative picture, not a force calculation. OpenStax notes that high-speed trains such as Japan's Yamanashi test line levitate on strong superconducting magnets, eliminating friction with the track.

5. Meissner effect vs. a "perfect conductor"

Is a superconductor just a material with R = 0? Test it. Apply a magnetic field and compare a superconductor with a hypothetical perfect conductor (R = 0 only). Uses the material and temperature chosen in part 1.

Key idea: with R = 0 alone, induced currents can only oppose changes in flux (Lenz's law), so a perfect conductor keeps whatever flux was inside when it was cooled. A superconductor expels the field whatever the order, which is the Meissner effect. Bc(T) ≈ Bc0[1 − (T/Tc)²] is a common approximation (not from OpenStax); Bc0 is the critical field listed in OpenStax Table 9.3 (mercury 0.04 T, NbTi 15 T, YBCO 120 T).

Material values are illustrative. Copper uses OpenStax Table 9.1 (ρ₀ = 1.68×10⁻⁸ Ω·m at 20 °C, α = 3.9×10⁻³ /°C); other normal-state values are rough approximations for demonstration. Tc and critical fields from OpenStax Table 9.3: mercury 4.15 K (Type I), NbTi 10 K (Type II), YBCO 92 K (Type II). Reference: Ling, S. J., Moebs, W., & Sanny, J. (2016). University physics volume 2.
