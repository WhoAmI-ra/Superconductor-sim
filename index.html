4. Meissner effect: magnetic levitation

Below Tc the superconductor expels the magnet's field, so the magnet floats. Warm it above Tc (use the slider) and it loses levitation. Only works when a superconducting material is selected.

Field lines bend around the superconductor because B inside it is zero. This is a qualitative picture, not a force calculation. Real Maglev trains use superconducting magnets aboard the train with guideway coils.

5. Meissner effect vs. a "perfect conductor"

Is a superconductor just a material with R = 0? Test it. Apply a magnetic field and compare a superconductor with a hypothetical perfect conductor (R = 0 only). Uses the material and temperature chosen in part 1.

Key idea: with R = 0 alone, induced currents can only oppose changes in flux (Lenz's law), so a perfect conductor keeps whatever flux was inside when it was cooled. A superconductor actively expels the field whatever the order, which is the Meissner effect. Bc(T) ≈ Bc0[1 − (T/Tc)²] is a standard approximation; Bc0 values here are illustrative (upper critical field for NbTi and YBCO).

Material values are illustrative. Copper uses OpenStax table values (ρ₀ = 1.68×10⁻⁸ Ω·m at 20 °C, α = 3.9×10⁻³ /°C); other normal-state values are rough approximations for demonstration. Tc: mercury ≈ 4.15 K, NbTi ≈ 9.2 K, YBCO ≈ 92 K. Reference: Ling, S. J., Sanny, J., & Moebs, W. (2016). University physics volume 2. OpenStax. https://openstax.org/books/university-physics-volume-2
